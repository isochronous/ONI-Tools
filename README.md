# ONI Tools

Tools around [Oxygen Not Included](https://www.klei.com/games/oxygen-not-included) and isochronous's [ONI mods](https://github.com/isochronous/ONI-Mods).

| Tool | What it is |
|---|---|
| [oni-loops](oni-loops) | A web app that finds every way to get more of a resource, from data a mod dumps out of the game. Live at https://isochronous.github.io/ONI-Tools/ |
| [oni-freeze](oni-freeze) | Scripts that keep a specific game build with a specific set of mods playable beside the auto-updating Steam install. |

`oni-loops/common` is [oni-mods-common](https://github.com/isochronous/oni-mods-common) as a submodule; clone with `--recurse-submodules`.

oni-loops was a repository of its own until October 2026; its history was brought here with it.
