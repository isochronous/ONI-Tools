# ONI Loops

A small web app for [Oxygen Not Included](https://www.klei.com/games/oxygen-not-included): pick a resource you want more of, say what your colony has (DLCs, which asteroid, which geysers and how many, which critters, how many Duplicants), and get every way to get more of it: loops that bring it back to itself first (net-positive, then "top-up" loops above a floor you set), then every process that makes it, with each input rated renewable / finite on your asteroid / on another planetoid / space material / no source. Loops where the target only rides along a machine that mostly eats something else are marked side-stream and listed last.

A plant is shown as a farm, with its irrigation and fertilizer in the chain, and the wild-planted version (a quarter of the growth, needing nothing) as an alternative on that step; the wild plant is a route of its own only where tending the plant needs something the colony cannot get. Critter egg rates follow happiness the way the game's HappinessMonitor sets it: 1 + 2.25 × happiness while above 0, none at −10, and a fifth of the appetite at −1 or below. The colony panel's ranching choices (grooming +5, a Critter Fountain with Brackene +5 or Squid Ink +3, a Critter Condo +1, on top of tame −1) set every critter's happiness, each overridable; a fountain's 5 kg a cycle per critter is shown with the step and summed under the chain, not sourced by the search. Routes that need more of something than a colony would build at the asked rate (fifty plants, thirty critters, ten buildings, or the geysers and terrain features found) are listed after the ones that do not, the less strained first.

Live: https://isochronous.github.io/oni-loops/

## Layout

- `app/`: the site (Vue 3, TypeScript, Vite). `npm install && npm run dev` to work on it.
  The colony panel can read a map seed (the game's coordinate, e.g. `V-SNDST-C-42-0-4A-MUWF1`): it runs [@onimaxxing/worldgen](https://www.npmjs.com/package/@onimaxxing/worldgen), a WASM reimplementation of the game's worldgen, in a web worker (the 11 MB engine loads only when a seed is read) and fills in the asteroid and the geysers and terrain features each world places, with the counts following the ticked worlds (the start world by default) and staying editable. The engine is not the game and its output is not verified here, so the page says the counts were read from the seed. The engine is [onimaxxing's worldgen](https://onimaxxing.com/worldgen) (MIT; the licence is in `app/src/worldgen/` beside the worker that loads it), credited in the page footer and next to the seed field.
  The look is the game's own: its UI face, Liberation Sans (the game's "Liberation Sans SDF"; subset to Latin in `app/src/assets/fonts/`, SIL Open Font License alongside), the dark HUD bar, and the cream windows with blue-grey title strips of the Vitals and Consumables screens; the dark theme (switch in the top bar, remembered in the browser) is its tooltips, warm charcoal with the same accents turned down.
- `tools/OniDataDump/`: a local-only game mod that writes `oni-data-dump.json` (every material conversion the game defines, with DLC restrictions) when the main menu opens. Built like the other isochronous mods via the `common/` submodule.
- `data/`: the dumped JSON the app ships with, one file per game build and DLC set (`<build>-all-dlcs.json` with Spaced Out!, `<build>-no-spaced-out.json` without; the content packs only add things and are filtered in the app). Import a fresh dump with `python tools/import-dump.py`. Note that the game enables mods per DLC mode, so the dump mod has to be enabled once in the Mods menu after switching Spaced Out! on or off.

The game data is read from the running game rather than from the source, because many conversions (critter diets, geysers, worldgen) only exist once the game has built them, and that is also where the DLC gating is authoritative.
